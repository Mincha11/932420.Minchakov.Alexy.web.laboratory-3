## Описание проекта

В данной лабораторной работе создана веб-страница на тему «Геймер и разработчик игр».

На странице представлены: информация о студенте;  навыки разработчика игр; проекты и игры, которые вдохновляют; карточки любимых игровых жанров; статистика игрового времени; любимые игровые технологии; форма обратной связи; изображения игровых проектов.
